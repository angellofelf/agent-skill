# AI 代码统计工具使用教程

> 本教程指导如何使用 `ai-code-check` skill 进行 AI 生成代码统计

---

## 前置准备

### 1. 确认项目结构

确保项目根目录存在以下文件：

```
fe-kongming/
├── AI-CONFIG/
│   ├── AI-GENERATED-MARKING-GUIDE.md    # AI 标记规范指南
│   └── AI-CODE-CHECK-USAGE.md           # 本教程
├── AI-Generate/                          # 统计报告输出目录
│   └── {username}/                       # 个人报告目录
└── src/                                  # 项目源码
```

### 2. 获取你的 Git 用户名

```bash
git config user.name
```

记录输出结果（如 `aurorayang`），生成报告时会用到。

## 使用流程

### 第一步：将标记规范添加到 AI 上下文

**在让 AI 生成代码之前，必须先将标记规范添加到对话上下文。**

#### Lingma IDE 操作方式：

1. **方式一：直接引用文件**
   - 在 AI 对话中输入：`@AI-CONFIG/AI-GENERATED-MARKING-GUIDE.md`
   - 或拖拽文件到对话窗口

2. **方式二：通过上下文菜单**
   - 在文件树中右键点击 `AI-GENERATED-MARKING-GUIDE.md`
   - 选择"添加到上下文"或"引用文件"

3. **方式三：使用指令**
   ```
   请先阅读 AI-CONFIG/AI-GENERATED-MARKING-GUIDE.md，然后帮我生成代码
   ```

#### 其他 AI 工具：

- **ChatGPT / Claude**：将文件内容复制粘贴到对话开头
- **Cursor**：使用 `@` 符号引用文件
- **VS Code Copilot**：在提示词中说明参考文件路径

---

### 第二步：让 AI 生成代码并自动标记

添加上下文后，正常描述你的需求，AI 会自动按照规范添加 `@ai-generated` 标记。

#### 示例对话：

**用户**：
```
@AI-CONFIG/AI-GENERATED-MARKING-GUIDE.md

请帮我创建一个用户管理模块，包含增删改查功能
```

**AI 会生成类似这样的代码**：

```typescript
/**
 * @ai-generated by aurorayang
 * @date 2026-03-05
 * @description 用户管理模块
 */

export class UserManager {
  // @ai-generated-start by aurorayang 2026-03-05 添加创建用户方法
  createUser(data: UserData): User {
    const user = { id: generateId(), ...data };
    this.save(user);
    return user;
  }
  // @ai-generated-end
}
```

---

### 第三步：提交代码变更（自动触发统计）

生成代码后，提交到本地仓库，**统计会自动执行**：

```bash
# 查看变更
git status

# 添加变更到暂存区
git add .

# 提交代码（husky 钩子会自动触发代码统计）
git commit -m "feat: 你的功能描述"

# 确认提交
git log -1 --stat
```

> **自动统计说明**：
> - 项目配置了 husky `post-commit` 钩子
> - 执行 `git commit` 时会**自动触发** `/ai-check` 统计
> - 统计基于本次 commit 的代码变更
> - 报告自动生成到 `AI-Generate/{username}/` 目录

---

### 第四步：查看统计报告（如自动统计失败可手动执行）

#### 自动统计
正常提交后会自动生成报告，直接查看即可。

#### 手动执行（备用）

如果自动统计失败，可在 Lingma IDE 中手动执行：
或让自己使用的工具 读取 .lingma/skills/ai-code-check/SKILL.md 然后允许/ai-check 也是一样的

```
/ai-check
```

或指定用户名：

```
/ai-check --username=yourname
```

---

### 第五步：查看统计报告

统计完成后，报告会生成在：

```
AI-Generate/{your-git-username}/
├── ai-code-report-{日期}-{commit-message}.md    # 详细报告
├── summary.md                                    # 汇总统计
└── ...
```

#### 报告内容示例：

```markdown
# AI 代码生成检查报告

## 统计摘要

| 指标 | 数值 |
|------|------|
| 变更文件总数 | 5 |
| 新增代码行数 | 105 |
| AI 生成代码行数 | 105 |
| AI 代码占比 | 100.0% |

## AI 生成文件清单

| 文件路径 | AI 生成行数 | 标记类型 |
|----------|-------------|----------|
| src/user.ts | 21 | 完整文件 |
```

## 常见问题

### Q1: AI 没有自动添加标记怎么办？

**解决**：在需求描述中明确要求添加标记

```
@AI-CONFIG/AI-GENERATED-MARKING-GUIDE.md

请帮我生成 X 功能代码，**必须按照上述规范添加 @ai-generated 标记**
```

### Q2: 统计报告显示 AI 代码占比为 0？

**检查项**：
- [ ] 代码中是否包含 `@ai-generated` 标记？
- [ ] 是否已执行 `git commit` 提交变更？
- [ ] 标记格式是否正确？（参考规范文档）

### Q3: 如何修改已生成的标记？

手动编辑文件，按照规范调整标记格式，然后重新执行统计。

### Q4: 报告中的用户名不正确？

执行时指定正确的用户名：

```
/ai-check --username=正确的用户名
```

## 最佳实践

1. **每次生成代码前都添加规范上下文**
   - 养成习惯，先引用规范再提需求

2. **及时提交和统计**
   - 代码生成后先 `git commit`，再执行 `/ai-check`

3. **定期检查汇总报告**
   - 查看 `AI-Generate/{username}/summary.md` 了解整体统计

4. **保持标记规范**
   - 不要手动删除或修改 AI 标记
   - 人工修改的代码不要添加 AI 标记
